What we found

A reseller with a thousand items a month is not running a store. They are running a data-entry department with one employee.

We walked the workflow end to end. Shoot the item. Rename the files. Sort the shots into piles per item. Open the eBay form. Retype the brand, size, colour, and condition that the photos already show. Open three tabs of sold comps. Guess a price. Fill the aspects eBay rejects you for missing. Repeat. For each item.

Every tool we looked at attacked the last five minutes of that: a faster form, a bulk uploader, a spreadsheet template. Nobody asked the earlier question: how much of this work needs a person at all?

Pare

The photos already contain the listing. So why is anyone typing it?

Steps we removed

  • File renaming. The filename was never the data. The image is.
  • Manual photo sorting. Grouping shots into items is pattern matching, not judgement.
  • Retyping attributes. Brand, size, colour, and condition are visible in the shots.
  • Comp tabs. Pricing research is a query, not an afternoon.
  • Aspect roulette. Missing required fields should fail before eBay, with the field named.
  • Copy-pasting policies. Payment, return, and fulfillment get set once per store.

Steps we kept

  • Shooting the item. Only a human can put the flaw in frame.
  • Approving the draft. The seller's name is on the listing. They read it before it goes.
  • Setting the floor. Comps advise. The seller decides what they won't go under.
  • Pressing publish. Nothing goes live on an eBay account without a confirmed instruction.

Four steps left. Everything else was habit wearing the costume of work.

Sync

What survived, we automated in lockstep. A folder of photos in, live listings out.

Connect the store

Once, in the browser. eBay sign-in, merchant location, and the three store policies. No API keys pasted into an editor, ever.

Drop the photos

Point FlipTide at the shoot folder. Photos upload straight to signed storage. FlipTide never touches the rest of the machine.

Group into items

Vision sorts the batch into items with front, back, and detail shots, and tells you what it couldn't place instead of guessing.

Draft and price

Title, aspects, and condition come from the images. Sold comps come back with the draft, so the price arrives with its evidence attached.

Read, then publish

The seller reviews, edits anything, and confirms. Publishing takes an explicit confirm. Missing required aspects fail before eBay sees them, with the field named.

The build decision

We didn't build an app. Nobody needs another dashboard between them and eBay.

FlipTide ships as an MCP server. Resellers already have Cursor or Claude open; they add one URL and the tools appear where they're already working. No new login to learn, no tab to keep alive, no UI we have to maintain in place of the one they chose.

That is the same instinct as the process work. Remove the layer that only exists because software usually comes with one.

Add FlipTide where you already work

FlipTide is a remote MCP server. Add the URL once in Cursor or Claude and the listing tools show up in the chat you already have open.

Development endpoint for now. When production is live, this page will point at the production URL instead.

Cursor: merge into mcp.json 
{
  "mcpServers": {
    "fliptide": {
      "url": "https://dev.fliptide.parsync.io/mcp"
    }
  }
}

Cursor

  1. Open Cursor Settings, then MCP, and edit your config (or open ~/.cursor/mcp.json).
  2. Merge the block above under mcpServers. Keep your other servers; add or replace the fliptide entry.
  3. Save and reload the window if the FlipTide tools do not appear. Run connect when the assistant asks you to sign in to eBay.

Claude

  1. In Claude (desktop or web), open settings for Connectors or MCP and add a custom remote server.
  2. Paste this URL: https://dev.fliptide.parsync.io/mcp. Claude does not use Cursor's mcp.json file; the URL is what both clients share.
  3. Complete sign-in when prompted, then ask the assistant to run ensure_account_ready or connect_ebay to link your store.
